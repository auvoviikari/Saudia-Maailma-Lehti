Kirjaudu toimitukseen

Uutiset tallennetaan suoraan GitHub-repoosi. Vain henkilö, jolla on kirjoitusoikeus repoon (eli sinä), voi julkaista. Tarvitset GitHub-tokenin: GitHub → Settings → Developer settings → Fine-grained tokens → valitse vain tämä repo ja anna oikeus Contents: Read and write. Token tallentuu vain tämän selaimen muistiin.
